讲义生成器 Flash 1.1（讲义工作台）
====================
（独立重构版，与原版 V1.0 互不影响，可同时运行）

【启动方式】
  1. 双击「启动讲义生成器.vbs」→ 自动打开浏览器（无黑窗口，推荐）
  2. 「讲义生成器.exe」为备用启动器，若双击无反应请用方式 1
  3. 浏览器未自动打开时，手动访问 http://127.0.0.1:5127

【使用流程】
  ① 在右侧配置学科、学段、年级、课程类型、学年、模板和分块方式
  ② 添加素材：.zip（内含成对 docx）或 .docx
  ③ 两个 Word 文件可选择「成对」或「各自生成」
  ④ 开始生成 → 完成后下载，或直接打开桌面「生成讲义结果」文件夹

【工作台功能】
  - 文件查重、类型和总大小检查
  - 删除、清空及撤销素材操作
  - 任务进度、耗时、警告和断线重连
  - 本次运行内的生成记录与成品入口
  - 真实 Word 模板首页预览
  - 分块策略只保留“智能分块（推荐）”和“完整保留”；选中后右侧会直接说明适用场景、处理步骤，以及是否保留原有结构
  - 浅色 / 深色 / 跟随系统外观

【运行方式】
  Flash 1.1 全程离线，不调用 DeepSeek，不上传文档内容。

【目录结构】
  res\python\             Python 3.12 运行时（自带依赖，免安装）
  res\app\                ★ 应用代码
    ├─ config.py          路径与配置唯一入口
    ├─ logger.py          统一日志（logs\ 目录，不再写桌面）
    ├─ docutils.py        段落扫描 / 主题提取 / 文件名
    ├─ objectives.py      教学目标与重难点生成
    ├─ student_ops.py     学生版加工（去答案/删标记/留白）
    ├─ runner.py          PowerShell 执行 + 生成编排
    ├─ handout.py         命令行入口（simple / plan / scan）
    ├─ split_engine.py    智能拆分引擎（LLM→混合→TOC→启发式 四层降级）
    ├─ hybrid_split.py    混合拆分（离线规则+NLP）
    ├─ llm_split.py       LLM 拆分（DeepSeek）
    ├─ toc_split.py       目录解析拆分
    ├─ *.ps1              Word COM 操作脚本（填充/扫描/留白/删答案）
    ├─ *.docx / *.doc     讲义模板
    └─ webapp\
       ├─ app.py          Flask 路由层
       ├─ jobs.py         后台任务服务
       └─ templates\      前端页面

【日志】
  运行日志在 res\app\logs\handout.log（滚动保留 3 份）。
  生成失败时，把该文件末尾内容发给我即可排查。

【与原版的关系】
  - 独立目录，不改动「讲义生成器V1.0」任何文件
  - 模板、PS1 脚本、拆分规则与原版一致，输出效果相同
  - 若确认 Flash 版稳定，可随时替换原版
