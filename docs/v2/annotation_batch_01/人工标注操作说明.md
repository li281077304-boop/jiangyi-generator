# 人工标注操作说明

## 准备

1. 打开 `样本清单.md`，按 ID 选择一份文档。
2. 同时打开原始 Word 文档和对应的 `dumps/Sxx.txt`；dump 用于精确定位，原件用于确认分页、版式和图文关系。
3. 打开对应的 `annotations/Sxx_标注.md`，只在副本里填写。原讲义只读。

## 标注顺序

1. 先标目录范围（若有）和正文起止；没有目录就写“无目录”。
2. 按阅读顺序标章节边界。一级章节不填父 ID，子章节填父章节 ID；纯标题行也纳入其章节范围。
3. 标完整题组：将题干、题目选项和题目必须依赖的材料范围纳入；连续小题按实际结构决定是一个大题组下含小题，还是多个独立题组，不需要猜出内容角色。
4. 对跨题共用的阅读材料，建立材料 ID，再列出它关联的题组 ID。
5. 标答案/解析范围，并填写能确定的对应题组；题目与答案无法可靠对应时写 `unknown`。
6. 对不能判断的位置填写 unknown 和原因，不要为了填满表格而推断。

## 如何写位置

- 正文块按 dump 左侧 `[seq pno]` 的 `seq` 标注，首尾都包含。例如 `12–19`。
- 若边界在表格内部，写 `T(12)/r2c1/p3`，代表顶层第 12 块表格、第 3 行第 2 列的第 4 个单元格段落（行、列、段落均从 0 开始）。按实际顺序再加结束位置。
- 若一个范围从顶层段落跨入表格，范围两端分别写顶层 `seq` 或单元格定位；不要仅凭扁平文本猜边界。
- 可以用短原文作锚点辅助定位；原文太长时摘录开头几个字即可。

## 标注尺度

优先标能确认的结构，不要求追求极细粒度。遇到重复题号、版面错乱、答案穿插、图片承载文字或 dump 无法表达的布局，记录范围和 unknown 原因。不要在本轮标“知识 / 例题 / 练习 / 巩固”，也不需要评价拆分是否合理。
