## 标注约定
- 以 dump 的 `[块序列]` 中 `seq` 作为边界位置；范围写成 `起seq–止seq`（含首尾）。表格内部请补充 `T(seq)/r行c列/p段`，例如 `T(12)/r2c1/p3`。
- 目录只标实际目录/目录页；正文从正文内容开始。看不清、文本抽取不足或边界有歧义时标 `unknown`，并写一句原因。
- 章节层级用父章节 ID 表达。完整题组要把题干、选项、必要共享材料都考虑进去；若材料被多个题共用，在“材料关系”里逐一关联。
- 本轮不判断“知识/例题/练习/巩固”，也不评价题目质量。
