# 讲义生成器 V1.2 正式版

Windows x64 · 免安装 · 无 OCR

## 开始使用

1. 将压缩包完整解压到本机可写的文件夹。
2. 双击 `讲义生成器/讲义生成器.exe`。必须保留旁边的 `_internal` 文件夹，不能只复制 EXE。
3. 程序会打开 Chrome；无需登录账号。如浏览器未自动打开，按程序提示打开本地地址。
4. 上传原始 DOCX 或包含 DOCX 的 ZIP，选择学科、年级以及“一对一”或“班课”模板，再点击生成。
5. 完成后点击“打开成品文件夹”，用 WPS 查看并复核 DOCX。

无需安装 Python、下载模型或克隆代码仓库。兼容处理需要本机已安装并完成首次启动设置的 WPS 或 Microsoft Word。

## 输入与成品

- 支持教师/学生两份资料、教师单份、学生单份及 ZIP 批量输入。
- 教师版/解析版/背诵版与学生版/原卷版/默写版会结合专题名进行配对。请保留原始版本名称，避免混淆不同专题。
- 两份资料分别读取各自原稿，不把教师答案复制到学生稿；不保证所有输入均完成逐题对应。
- 只提供教师版时，不能证明自动去答案安全的输入只交付教师版并提示。自动生成的学生版仍须复核答案、红字、解析、公式和表格。
- 自动分槽优先使用原文栏目和可靠识别结果，再在完整题目或题组之间按约7∶3分配训练内容。
- 知识精讲使用真实原文；没有独立讲解时可使用一个完整源题组作为例题研读，不编造知识内容、不重复填充题目。
- 无法安全分槽时，明确显示“保留原文，未完成分槽”；无法证明内容完整时显示失败，不冒充成功。
- 教学目标、重点难点没有可靠来源时留空，并在任务中提示补充。

正式成品保存到桌面 `生成讲义结果` 目录。ZIP 是输入格式，成品为 DOCX，不提供浏览器 ZIP 下载。

## 使用注意

- 不包含 OCR 和识别模型，图片内文字不识别。图片、公式、表格按源内容复制保留。
- 上传前确认磁盘空间充足。页面断线不会取消后台任务，可点击“重新连接”或刷新恢复任务状态。
- 通过应用内“退出程序”正常关闭；使用前检查成品题目、答案、图片、表格、公式和分页。
- 部分复杂或损坏的文档仍可能失败，请保留原始文件并查看任务详情中的原因。

## 版本说明

本版按用户本机实际试用确认收口，修复了知识清单的背诵版/默写版配对和训练栏目分配。采用完整文件夹交付，无安装器、无自动更新。
