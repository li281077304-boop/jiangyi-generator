# 讲义生成器 V1.2 RC

## 运行前

- Windows x64。
- **无需安装 Python**，也不需要克隆项目仓库或创建开发虚拟环境。
- **稳定模式（V0.9 引擎）需要本机已安装并注册 WPS 或 Microsoft Word**，以便调用文档自动化功能；当前实机验收环境为 WPS。
- 将整个 `讲义生成器` 文件夹解压到本机可写位置，再双击 `讲义生成器.exe`。不要只复制单独的 EXE 文件。

## 生成讲义

1. 启动程序后，在浏览器工作台选择“稳定模式（V0.9 引擎）”。
2. 选择模板：**1对1**或**班课**。
3. 添加 DOCX 文件，或添加包含 DOCX 的 ZIP 文件。ZIP 仅作为**输入格式**；程序不生成 ZIP 成品包。
4. 保留原文件中的教师版/解析版、学生版/原卷版名称；工作台会结合文件名和内容判断角色，并优先使用已有学生稿。
5. 开始生成。任务成功后，打开页面提供的成品文件夹。

成品保存在桌面 `生成讲义结果` 下，每个任务使用独立文件夹。正式输出为 DOCX。

### 教师版单文件

只提供教师版时，程序会使用现有处理能力生成学生版。自动处理不能保证删除所有答案、解析或公式中的答案信息。**使用前请人工检查学生版，尤其是红字答案、解析、公式和表格。**

### 学生版单文件

只提供学生版时，按所选模板生成学生版成品；程序不会从学生稿推测或补写教师答案。

## XML 模式

XML 模式是单独选择的受限能力，适用于其当前明确支持的文档结构。它不会在失败后自动切换到 V0.9。遇到不支持的输入时，任务会明确报告失败原因；需要继续处理时，请重新选择稳定模式并提交原始输入。

## 文件和故障处理

- 生成过程和中间文件保存在用户本机；成品以桌面结果目录中的 DOCX 为准。
- ZIP 下载不是交付步骤；请使用“打开成品文件夹”。
- 若任务失败，先查看任务详情中的失败原因。请保留原始 DOCX/ZIP，以便再次尝试或反馈问题。
- 稳定模式依赖本机 WPS/Word 自动化。如果应用未安装、未完成首次启动设置或无法正常启动，稳定模式可能无法生成成品。
