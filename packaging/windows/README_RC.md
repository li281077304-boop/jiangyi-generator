# 讲义生成器 V1.2 抢救测试版

本包供真人测试，尚不是正式发布版。部分复杂文档仍可能明确失败。

## 运行前

- Windows x64。
- 浏览器工作台自动使用 Chrome，无需登录账号。未安装或无法启动 Chrome 时会显示可手动打开的本地地址。
- **无需安装 Python**，也不需要克隆项目仓库或创建开发虚拟环境。
- **兼容处理需要本机已安装并注册 WPS 或 Microsoft Word**；当前实机验收环境为 WPS。程序自动选择处理路径，用户无需选择引擎。
- 系统盘和成品目录所在盘均需要充足空闲空间。
- 将整个 `讲义生成器` 文件夹解压到本机可写位置，再双击 `讲义生成器.exe`。不要只复制单独的 EXE 文件。

## 生成讲义

1. 启动程序后打开浏览器工作台，无需选择引擎。
2. 选择模板：**1对1**或**班课**。
3. 添加 DOCX 文件，或添加包含 DOCX 的 ZIP 文件。ZIP 仅作为**输入格式**；程序不生成 ZIP 成品包。
4. 保留原文件中的教师版/解析版、学生版/原卷版名称；工作台会结合文件名和内容判断角色，并优先使用已有学生稿。
5. 开始生成。任务成功后，打开页面提供的成品文件夹。

成品保存在桌面 `生成讲义结果` 下，每个任务使用独立文件夹。正式输出为 DOCX。

### 教师版单文件

只提供教师版时，只有经过安全证据检查的输入才自动生成学生版。不能证明安全时只交付教师版并明确提示，不会把教师稿当学生稿。**自动生成的学生版仍需人工复核，尤其是红字答案、解析、公式和表格。**

### 学生版单文件

只提供学生版时，按所选模板生成学生版成品；程序不会从学生稿推测或补写教师答案。

## 自动处理与已知限制

程序优先使用原文栏目和已有识别结果，再尝试完整题组约7∶3分配。不确定的题号不重排，两份原稿各自生成，不保证逐题对应。

知识精讲保留真实原文内容。原文没有独立知识讲解时，将第一个完整题组作为例题研读，其余完整题组进入训练槽；页面会提示这一处理方式，不自动编写知识总结。无法安全分出三个部分时，按原文顺序保全并显示“分槽未完成”，不冒充正常分槽成功。不能保留知识精讲内容时停止交付并给出原因。

本测试包不包含本地OCR、模型或自动下载功能。图片内文字不识别，图片、公式和表格仍按原文及所属题组保留。

只有 XML 技术上不能完成时才尝试 V0.9 兼容处理，两条路径均执行成品检查。无法证明内容完整时停止交付，不会记作成功。氧气专题中内容与格式一致的双份文本框表示已通过内部投影保留，并有两种模板的 XML / WPS 验证；不等价或不支持的文本框结构仍需检查，兼容路径遗漏内容时会拦截交付。

目标/重难点没有可靠来源时留空并提示补充。完整回归和全部语料内容验收尚未通过；使用前请打开成品检查题目、答案、图片、表格、公式和分页。

## 文件和故障处理

- 生成过程和中间文件保存在用户本机；成品以桌面结果目录中的 DOCX 为准。
- ZIP 下载不是交付步骤；请使用“打开成品文件夹”。
- 若任务失败，先查看任务详情中的失败原因。请保留原始 DOCX/ZIP，以便再次尝试或反馈问题。
- 页面断线不会取消后台任务。恢复网络后点击“重新连接”；刷新或重开网页可以恢复已保存任务。
- 兼容处理依赖本机 WPS/Word 自动化。如果应用未安装、未完成首次启动设置或无法正常启动，兼容处理可能失败。
